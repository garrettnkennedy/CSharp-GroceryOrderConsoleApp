This program is a digital grocery store simulation written in C#.
The user can enter input as if they were signing into a grocery store website, and then Add and Remove items from their digital grocery cart and Exit to exit the program. With different behavior if the user decided to add anything to their card or Exit with an empty cart.
it can be compiled with dotnet build and ran with dotnet run, and then following the programs prompts. There is code to make users re-enter input if they enter invalid input.

This program demonstrates console application development, user input handling, loops and conditional logic, order calculation, and basic debugging practices.
